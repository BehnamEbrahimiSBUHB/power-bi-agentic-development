# Visual vocabulary

What people call the things they see, mapped to `<object>.<property>` paths per visual type. It is an offline snapshot; `pbir schema elements <type> [element]` (or `--visual <path>` on a concrete visual) is authoritative and also shows which properties are set. Types with identical maps share one file. `visualContainer` applies to every visual (title, background, border, shadow, tooltip, header).
